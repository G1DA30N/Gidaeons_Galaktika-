# Gidaeon's Galaktika Source Build Instructions

This source package contains the unminified, unbundled source files used to create the submitted Firefox add-on ZIP and the parallel Chromium Manifest V3 ZIP.

## Build Environment

Required operating system:

- Windows 10 or Windows 11

Required build tool:

- Windows PowerShell 5.1 or newer
- .NET compression assemblies included with Windows PowerShell

No Node.js, npm, webpack, Babel, TypeScript, minifier, transpiler, or third-party package install is required to build the submitted add-on archive.

Optional runtime tools for the separately installed local helper:

- Python 3.13 or 3.14 from python.org
- `ffmpeg`

The helper installer creates a local virtual environment and installs `yt-dlp`, two PO-token provider plugins, and Chromium cookie snapshot support. It also downloads a pinned bgutil script runtime. These runtime packages are not used to build or bundle the extension ZIP.

These optional runtime tools are not used to build the Firefox extension ZIP. They are only used when running the local helper after installation.

## Source Layout

The Firefox add-on source files are:

```text
manifest.json
manifest.chromium.json
src/
popup/
assets/galaktika-16.png
assets/galaktika-32.png
assets/galaktika-48.png
assets/galaktika-96.png
assets/galaktika-128.png
```

The native helper source is included for review context under:

```text
native/
```

The native helper is not bundled into the submitted Firefox extension ZIP. It is installed separately by users who want waveform prefetching, downloads, and toolbar diagnostics. Firefox launches it on demand through native messaging.

## Build Steps

From the source package root, run:

```text
Build-Submission.cmd
```

Or directly:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\Build-Submission.ps1
```

The script performs these steps:

1. Deletes and recreates `dist-submission/`.
2. Copies only the Firefox add-on runtime files into `dist-submission/firefox-extension/`.
3. Copies the Chromium Manifest V3 runtime files into `dist-submission/chromium-extension/` and renames its source manifest to `manifest.json`.
4. Copies the native helper files into `dist-submission/helper-installer/`.
5. Creates ZIP files using forward-slash archive paths required by extension stores.
6. Writes both browser add-on ZIPs to `dist-submission/packages/`.

## Expected Output

For version `0.1.80`, the submitted Firefox add-on archive is:

```text
dist-submission/packages/gidaeons-galaktika-firefox-0.1.80.zip
```

The archive should contain exactly:

```text
assets/galaktika-128.png
assets/galaktika-16.png
assets/galaktika-32.png
assets/galaktika-48.png
assets/galaktika-96.png
manifest.json
popup/popup.css
popup/popup.html
popup/popup.js
src/background.js
src/browser-compat.js
src/content.js
src/page-clipboard-hook.js
src/radiooooo-page-bridge.js
src/site-url-bridge.js
src/styles.css
```

The parallel Chromium archive is:

```text
dist-submission/packages/gidaeons-galaktika-chromium-0.1.80.zip
```

It additionally contains `src/background-chromium.js`, and its packaged `manifest.json` is generated by copying `manifest.chromium.json` without transforming its contents.

## Generated Files

The build does not transpile, concatenate, minify, or otherwise transform JavaScript or CSS source files. It copies source files as-is and packages them into a ZIP archive.

The following directories are generated by the build and are not source:

```text
dist-submission/
```

Local runtime caches, logs, and Python bytecode are intentionally excluded from the source and submission packages.
